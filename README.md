
# Sales Analytics Interactive Dashboard

## Project Description

The Sales Analytics Dashboard is a Python-based
data visualization project.

It helps businesses understand sales performance
using interactive charts, graphs, filters and reports.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Plotly
- Streamlit

## Features

1. Total Revenue Analysis
2. Total Orders
3. Products Sold
4. Average Order Value
5. Monthly Revenue Analysis
6. Category-wise Sales
7. Product-wise Sales
8. Regional Sales Distribution
9. Payment Method Analysis
10. Top Selling Products
11. Interactive Filters
12. Download Sales Reports

## Project Structure

Sales-Analytics-Dashboard/
- app.py
- sales_data.csv
- requirements.txt
- README.md

## Installation

Step 1: Clone or download the project.

Step 2: Install Python.

Step 3: Open the project folder in VS Code.

Step 4: Install required libraries.

```bash
pip install -r requirements.txt
```

Step 5: Run the application.

```bash
streamlit run app.py
```

Step 6: Open the dashboard in your browser.

http://localhost:8501

## Project Objective

To understand business sales data and convert
raw data into meaningful visual insights.
